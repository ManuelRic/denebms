# Deneb Machinery Services

Rediseño estático, responsive y accesible del sitio corporativo de Deneb Machinery Services.

## Vista local

Sirve la raíz del repositorio con cualquier servidor HTTP estático. El punto de entrada es `index.html`.

## GitHub Pages

El sitio está preparado para publicarse desde la rama `main`, carpeta `/ (root)`, en GitHub Pages. `index.html`, las páginas legales, los estilos, el JavaScript y `assets/` deben permanecer juntos en la raíz. El archivo `.nojekyll` permite servirlos como archivos estáticos.

Sitio publicado: https://manuelric.github.io/denebms/
